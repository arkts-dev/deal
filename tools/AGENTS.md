# Tools

Maintain reproducible build/test/launcher/packaging utilities. Fail fast, quote paths, avoid checkout assumptions and governance artifacts; synchronize policy. `gate-manifest.sh` alone selects suites for `run_tests.sh` and coverage; no alternate profiles. Java suites run sequentially. Compile tests separately into `build/test-classes`; report only production classes in `build/deal`. Enforce unrounded 80% line and 70% branch minima; never weaken limits to hide regressions. Measure runtime with command, revision, wall time, and load; distinguish work-count savings from speedups. Disclose skips and lost execution lanes.
