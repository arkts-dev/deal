# Tools

Maintain reproducible source-checkout build/test utilities. Fail fast, quote paths and avoid governance artifacts; synchronize policy. There is no separate distribution build, installer, launcher or release-verification workflow. `gate-manifest.sh` alone selects suites for `run_tests.sh` and coverage; no alternate profiles. Java suites run sequentially. Compile tests separately into `build/test-classes`; report only production classes in `build/deal`. Enforce unrounded 85% line and 75% branch minima; never weaken limits to hide regressions. Measure runtime with command, revision, wall time, and load; distinguish work-count savings from speedups. Disclose skips and lost execution lanes. The default TypeScript compiler syntax gate checks the normative, language-guide, capability-demo and bundled skill examples, stdlib, checked-AST observer golden fixtures, v1.5 regressions and all positive/runtime corpus sources, companions and host declarations; compile-error fixtures alone are excluded because they intentionally contain invalid grammar. Select by declared intent, never current compiler outcomes, and reject unknown classification. Include compiler grammar/context diagnostics from the 1xxx family as well as parser diagnostics; TypeScript 4.5 does not expose all grammar failures through getSyntacticDiagnostics. Execute independent checker controls for parser failure, throw-newline, octal and await context, with a type-only mismatch accepted to keep TS semantic typing separate.
