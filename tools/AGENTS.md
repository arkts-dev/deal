# Tools

Maintain reproducible build/test/launcher/packaging utilities. Fail fast, quote paths, avoid checkout assumptions and governance artifacts; synchronize policy. `build-release.sh` requires the matched v1.4 runtime, driver, declaration, and stdlib implementation assets and ships that complete set; `verify-release.sh` compiles and executes the packaged smoke project on every supported backend outside the checkout and rejects old versions, missing or mismatched resources, broken deployment copies, and failing executions. No dev gate invokes either script. Removed source-version directives in packaged declaration negatives report E1044, not a version-compatibility diagnostic. `gate-manifest.sh` alone selects suites for `run_tests.sh` and coverage; no alternate profiles. Java suites run sequentially. Compile tests separately into `build/test-classes`; report only production classes in `build/deal`. Enforce unrounded 80% line and 70% branch minima; never weaken limits to hide regressions. Measure runtime with command, revision, wall time, and load; distinguish work-count savings from speedups. Disclose skips and lost execution lanes.
