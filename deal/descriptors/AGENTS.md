# Descriptors

Own strict canonical Type-to-text encoding, byte-stable rendering, inverse parsing and matching. Data parsing rejects void at the root, in arrays, nullable envelopes and parameters. Explicit result parsing admits bare void only at the outer result position; nested function results also admit it. Boundary matching and async-export return validation use result parsing, without admitting void data containers. Arrays of void-returning functions remain valid. Semantic IR carries descriptors, never AST syntax or local aliases. Preserve binary64 values and independent nullish permissions. Value-model adapters explicitly identify undefined. Java string carriers preserve every UTF-16 unit; malformed byte transport rejects at ingress, never by rejecting legal lone units. Fail unsupported internal types before publication. Native raw-callable/opaque presentations are never admitted unknown data; recursive live checks recognize raw-callable and opaque host storage by their reference-free private layouts without widening persistent data tags. Record keys remain string-typed independently of hidden member values.
