# Descriptors

Own canonical runtime descriptors and matching. Maintain one strict Type-to-text authority, byte-stable rendering, and inverse parsing. Never invent local encodings; unsupported internal types fail before publication. Semantic IR carries canonical descriptors, never AST syntax. The numeric descriptor is `number`; matching preserves all binary64 values without magnitude refinement. Every value-model adapter explicitly identifies its undefined carrier; never default that predicate to false. Unknown preserves supported language data but does not exempt strings from Unicode-scalar validation. Keep this file always synchronized with code.
