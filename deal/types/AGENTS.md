# Types

Define canonical target-neutral checked types. Preserve structural equality, invariance, nullability, and function rules without runtime-representation assumptions. A class type carries the declaring module's wiring key as its defining provider when the carrier binds one: two bound providers of two same-named declarations are two declarations, so equality and assignment never retag a value across them; the canonical identity itself names the defining file, so two same-named sibling files are already distinct there. The unbound carrier (public descriptor synthesis, the builtin `Error`, retained harnesses) names no second declaration. Delegate textual descriptors to descriptor services. Coordinate changes with checker, lowering, boundaries, and tests. Keep this file always synchronized with code.
