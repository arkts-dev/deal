# Semantic IR

Define the validated, executable, backend-neutral compiler contract. Admit no AST or checker-owned objects; keep IDs, descriptors, payloads, ordering, and serialization deterministic. Evolve lowerer, validator, Oracle, every emitter, and tests atomically. The typed record surface and the canonical text surface feed one complete raw fact model through one composed admission: registry identities, body membership, the module-init/export-plan links, functions/captures, the complete binding variants (including the closure and adapter registration links) and the class-construction/default facts reject with the same first failure on both surfaces. `RawUnitMaterializer` is the canonical raw-to-typed inverse of `RawUnit.fromTyped`; it grants no authority and fails closed on an undecodable recognized position. A standalone unit runs the applicable local predicates and rejects every fact that requires the project's provider context (a CLASS_NEW under an imported/declared default owner, a SHARED_BODY external function of another module, an externalEntryRef naming another module) with the first E6005 at the referring subject; the complete-project surfaces resolve exactly those links from the supplied closure (the class owner runs where the carried interface index, seeds and surrounding modules supply the provider join). The typed and text project surfaces share one framing admission (module-map key/identity agreement, the carried profile, index coverage and provider classification, required in-project implementation providers and the dependency order of the resolved imports), and the production composition keeps its pinned per-module order (common-admission head, address chain, control flow, bindings, class construction) with each owner running once over exactly the unit's owned companion records. The carried `semanticProfile` is the single-profile owner's value at every constructor, validator and guard: the admitted name is derived from that owner, the lowering-context hash is recomputed from the carried active profile with the supplied capability-registry hash, and a carried profile that disagrees with the supplied comparison facts or with the project profile rejects with `R-PROFILE` — no path substitutes a removed v1.2 value or projects a hard-coded profile. Ultimate goal: all production backends consume this IR, retiring AST-consuming emitters. Architectural direction never expands assigned task scope. Keep this file always synchronized with code.
