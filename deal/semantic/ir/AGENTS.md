# Semantic IR

Define the validated, executable, backend-neutral compiler contract. Admit no AST or checker-owned objects; keep IDs, descriptors, payloads, ordering, and serialization deterministic. Evolve lowerer, validator, Oracle, every emitter, and tests atomically. The typed record surface and the canonical text surface feed one complete raw fact model through one composed admission: registry identities, body membership, the module-init/export-plan links, functions/captures, the complete binding variants (including the closure and adapter registration links) and the class-construction/default facts reject with the same first failure on both surfaces. `RawUnitMaterializer` is the canonical raw-to-typed inverse of `RawUnit.fromTyped`; it grants no authority and fails closed on an undecodable recognized position. A standalone unit runs the applicable local predicates (the class owner runs where the carried interface index, seeds and surrounding modules supply the provider join), and the production composition keeps its pinned per-module order (common-admission head, address chain, control flow, bindings, class construction) with each owner running once. Ultimate goal: all production backends consume this IR, retiring AST-consuming emitters. Architectural direction never expands assigned task scope. Keep this file always synchronized with code.
