# Semantic IR

Define the validated, executable, backend-neutral compiler contract. Admit no AST or checker-owned objects; keep IDs, descriptors, payloads, ordering, and serialization deterministic. Evolve lowerer, validator, Oracle, every emitter, and tests atomically. The typed record surface and the canonical text surface feed one complete raw fact model through one composed admission: registry identities, body membership and the module-init/export-plan links reject with the same first failure on both surfaces. Ultimate goal: all production backends consume this IR, retiring AST-consuming emitters. Architectural direction never expands assigned task scope. Keep this file always synchronized with code.
