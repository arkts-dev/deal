# Semantics

Own backend-neutral checked-project lowering and shared runtime meaning. Encode evaluation order, boundaries, failures, calls, classes, modules, and stdlib behavior once. Ultimate goal: product-enable semantic IR on every backend and retire AST-consuming emitters. Complete constructs vertically. An imported-class construction, default or field operation resolves the exact declaring provider: the recorded contextual provider alias selects the occurrence's declared construction entry and layout, and an unrecorded same-identity sibling pair fails closed rather than selecting a first alias. Project seed coherence resolves implementation classes through exact interface/module identity without fabricating declaration seeds; declaration seeds also agree with field operations and optional-read descriptors, including private classes with no construction. The bindings-production and class-construction owners admit the same complete facts on the typed and text surfaces: closure/record capture links, the complete registration variants against their producing operations, parameter/import facts against real allocations, and the factory/JSON-default/construction-entry agreements reject identically instead of repairing content. The composed per-module production admission consumes exactly the unit's owned companion records: a supplied body-table, parameter/import, class-factory or JSON-default view that differs from the unit rejects with E6005 `PROJECT_VIEW_MISMATCH` before any success, and a content-equal detached view is replaced by the owned record. The one project lowering threads the invocation's carried `semanticProfile` into every unit and project constructor, every comparison fact and every admission gate, so the produced unit/project profile and their lowering-context hashes derive from that carried value. The bindings owner's `IMPORT_OCCURRENCE_CORRELATION` rule correlates every function-typed HOST import read with the alias cell of the `MODULE_IMPORT` occurrence that materialized it, so the selectable occurrence is recorded once per source import and never re-derived from a module/name lookup. `HostDeclarationSurface.sortedByName` is the single ascending-name selection of JS declared-export validation/raw reads; the declaration-ordered provider facts stay untouched.
