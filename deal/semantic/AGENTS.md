## Bindings, calls and adapters

Each HOST import read records its source occurrence's alias cell; never reconstruct occurrence ownership from module/name. Declared-export validation uses shared ascending-name order without changing declaration-ordered provider facts.

A function binding assigned anywhere in its declaring body's nested traversal has no static allocation identity. Reads materialize the current value; calls/await use Dynamic dispatch. Never-assigned declarations, recursion and fixed adapter sources retain recorded static callees. Classify runtime sources by their recorded execution class, not spelling or descriptor.

Adapter capture modes remain distinct. REEVALUATE_THUNK resolves its expression per invocation; VALUE captures an evaluated source, including awaited completion; SHARED_CELL retains its cell. Preserve their recorded sync/async call and completion cells.

Assignment evaluates and yields the original RHS once. Storage may receive an adapter without changing the expression's type/identity. Assignment adapters capture VALUE; validators require the preceding RHS producer, correct parent/type/order and original publication. Later loads or enclosing assignments cannot justify earlier captures.

## Consumption and control flow

Lower checked refined binding reads through NARROWED_READ where no owning typed boundary already checks consumption: operators, conditions, index receiver/key, Record receivers, length, for-of and presence. Record the refined descriptor and read origin; consumers use the admitted result. Never rewrite declared-nullable reads, null tests or function-boundary reads. Preserve each owning boundary's projection, including E8003 array elements.

Address-chain receiver/key/normalize/commit facts reference the admitted operands without changing child order. Slot-threaded logical operands republish the caller's preallocated condition identity. For-of evaluates once and preserves live traversal and fresh mutable captured iteration cells.

Error throw/catch/rethrow keeps one reference identity, current code/message, original diagnostic facts and linked causes. Catch bindings obey ordinary lexical shadowing and fresh per-execution cells; closures retain the captured incarnation. A bare assignment target owns ASSIGNMENT, not an invented identifier read.

## Classes and JSON

Register structural class layouts and helper/provider facts before body lowering. Every nonoptional field, including nullable and Error fields, is required. Provided fields own declaration-order boundaries; omitted optionals remain absent. No initializer operation, default publisher or host defaults hook exists. Generated decoding rejects missing/extra keys and failed nested values without factories.

Preserve persistent descriptors on decoded typed arrays recursively, including empty arrays. Function assertions register execution materializations while preserving identity; assertion failures always use E8001 without replacing ordinary signature/element diagnostics.

Render canonical interfaces with Record<string, unknown>, Promise results and independent nullish flags ordered null then undefined. Do not reconstruct retired source/async spellings or conflate canonical record with diagnostic/JSON-plan table.

Class stringify follows private presence/declaration order and original cycle identity; Error exposes code/message only. Generic/generated Records omit object undefined/missing/functions, null-substitute arrays/nonfinite numbers, order numeric keys first, encode nested classes. Declared nonfinite numbers likewise encode null. Reject malformed Unicode/cycles. Parsed Record arrays retain unknown[] descriptors; declared fields retain declared descriptors.
