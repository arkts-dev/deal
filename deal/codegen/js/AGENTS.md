The renderer consumes `RuntimeDeclarationSurface`/`RuntimeDeclarationProjection` as the structural declaration seam and one artifact per implementation unit from `JsEmissionInput`. `ProductionProjectEmission.run` is its one production caller for `Backend.JS`: exactly one `emitProductionProject` invocation over the one lowered project, staged into the existing publication transaction as the complete artifact/map/runtime/stdlib set (`Result.artifactRelativePath` names the entry artifact; the produced project is the run's own once-lowered closure). A fail-closed rejection or an invalid input shape becomes the one E6005 SHARED_EMITTER_COVERAGE with the rejected operation's own origin when the signal carries one, and no artifact publishes. The renderer emits content and coordinate-only mappings, never lowering, filesystem effects, Node execution or host/default invocation, and it fails closed on an unsupported slice instead of rerouting.
