# JavaScript Backend

Preserve CommonJS ABI, source locations, runtime checks, and evaluation order. Current AST consumption is acceptable migration state, not architecture. Drive toward a semantic-IR emitter and retire AST walking after differential and end-to-end parity. `JsSemanticEmitter` is the semantic-IR renderer foundation that replaces the AST emitter at the atomic cutover (ISSUE-0805), with `RuntimeDeclarationSurface`/`RuntimeDeclarationProjection` as the structural declaration seam and one artifact per implementation unit from `JsEmissionInput`. The renderer emits content and coordinate-only mappings, never lowering, filesystem effects, Node execution or host/default invocation, and it fails closed on an unsupported slice instead of rerouting. Its realized families include the call/boundary slice: direct, indirect, occurrence-owned host and SHARED_BODY external calls; the runtime-resolved dynamic callee call/async start (the carrier's private class tag — `DEAL_BODY` for a lowered closure, `ADAPTER` for an adaptation wrapper, `HOST` for a host entry, host-materialized value or conversion intrinsic — selects the class path and the recorded per-class return cell, an adapter's own D15-resolved source selects its path — recorded on the wrapper instance created by that execution, so one adapt site executed repeatedly keeps every retained wrapper's own source record — and an unresolvable carrier fails closed with the pinned `expected function` row at the call origin; never a descriptor or a callee spelling); native-Promise `ASYNC_START`/`AWAIT` with the single await-site completion cell; the async adapter and cross-module async entry; the direct-run/require entry split that keeps the `$rt.invokeAsyncExport(entryExports, exportName, returnDescriptor)` ABI; and the `CALLBACK_INVOKE` host crossing on the published wrapper. `DEAL_TO_HOST`+`HOST_PARAMETER` parameter cells run the E8010 `$rt.hostParam` composition at their one-based call-site origin, never a masking generic descriptor check, and a `CONTEXTUAL_TABLE_READ` over a function, array or bytes carrier defers its check to the consuming declared cell (the shared oracle/LuaJIT/JVM rule). Its runtime linkage (`$rt.initModule`/`moduleSurface`/`publishModule`/`readModule`/`moduleState`/`callExport`/`registerFactory`/`callFactory`/`throwValue`/`invokeAsyncExport`, plus the carrier-neutral `tableGet`/`tableSet`/`tableDelete` index members over the Map and module-surface carriers and the `dynClass`/`dynFail`/`hostParam` dynamic-dispatch and host-cell adapters) lives in `deal/runtime.js` and carries representation only. Avoid deepening AST-only semantics. Classes render from the validated layouts/factory registries/interface entries: per-attempt default thunks give every construction a fresh scope (a supplied field skips its default, an absent optional stays absent, literal defaults are fresh and calls rerun), the private `ClassFactoryId` linkage carries the owner module's defaults-only transfer for imported-provider construction, local construction applies the recorded declaration-order boundaries and the pinned E8007 extra-key scan, and the public surface stays META `{$kind:'class',$classname:<public identity>}`, full-construction `C$new(provided,file,line,column)` and the exported `C$fromJson`/`C$toJson` wrappers over the hidden `C$fields` descriptor array (imported classes read the declaring module's published `C$fields`). The HOST/STDLIB boundary renders from the admitted occurrence facts and the structural declaration surface: one raw Node require per resolved host file and one validating `$rt.loadHost` per source HOST import declaration (the occurrence-owned typed surface with fresh wrappers and synthesized `C$new`/`C$fields` over the retained raw META/defaults references), every host read and call — direct, stored, namespace, host-driven callback and async — through that occurrence's own surface entry, the host-declaration class construction through the occurrence's synthesized `C$new`, and the once-only deployed stdlib surface behind the emitted relative require, whose cataloged `STDLIB_CALL` rows run the recorded `STDLIB_PARAMETER`/`STDLIB_RETURN` cells around the module's own wrapper. Relative specifiers keep the retained `relativeSpecifier`/`importRequireSpecifier` rules (an already-relative host spelling verbatim, no ambient `NODE_PATH`/`node_modules` resolution); a failed host load leaves the importing implementation sticky FAILED with no partial typed surface, and a malformed declaration link fails closed at the consuming op's own origin. The declared-export validation/raw-read order is the shared ascending-name selection (`HostDeclarationSurface.sortedByName`), each source HOST import owns its fresh typed surface over one raw Node require per resolved file, and the array for-of uses the shared live-position traversal (deleted-slot stop, visited contiguous appends, iterable evaluated once).
