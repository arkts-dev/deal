# JavaScript Backend

Preserve CommonJS ABI, source locations, runtime checks, and evaluation order. Current AST consumption is acceptable migration state, not architecture. Drive toward a semantic-IR emitter and retire AST walking after differential and end-to-end parity. `JsSemanticEmitter` is the semantic-IR renderer foundation that replaces the AST emitter at the atomic cutover (ISSUE-0805), with `RuntimeDeclarationSurface`/`RuntimeDeclarationProjection` as the structural declaration seam and one artifact per implementation unit from `JsEmissionInput`. The renderer emits content and coordinate-only mappings, never lowering, filesystem effects, Node execution or host/default invocation, and it fails closed on an unsupported slice instead of rerouting. Its runtime linkage (`$rt.initModule`/`moduleSurface`/`publishModule`/`readModule`/`moduleState`/`callExport`/`registerFactory`/`callFactory`/`throwValue`, plus the carrier-neutral `tableGet`/`tableSet`/`tableDelete` index members over the Map and module-surface carriers) lives in `deal/runtime.js` and carries representation only. Avoid deepening AST-only semantics. Classes render from the validated layouts/factory registries/interface entries: per-attempt default thunks give every construction a fresh scope (a supplied field skips its default, an absent optional stays absent, literal defaults are fresh and calls rerun), the private `ClassFactoryId` linkage carries the owner module's defaults-only transfer for imported-provider construction, local construction applies the recorded declaration-order boundaries and the pinned E8007 extra-key scan, and the public surface stays META `{$kind:'class',$classname:<public identity>}`, full-construction `C$new(provided,file,line,column)` and the exported `C$fromJson`/`C$toJson` wrappers over the hidden `C$fields` descriptor array (imported classes read the declaring module's published `C$fields`). The HOST/STDLIB, async and callback slices stay later units. The declared-export validation/raw-read order is the shared ascending-name selection (`HostDeclarationSurface.sortedByName`), each source HOST import owns its fresh typed surface over one raw Node require per resolved file, and the array for-of uses the shared live-position traversal (deleted-slot stop, visited contiguous appends, iterable evaluated once). Architectural direction never expands assigned task scope. Keep this file always synchronized with code.
