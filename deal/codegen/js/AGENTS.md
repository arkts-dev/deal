# JavaScript Backend

Preserve CommonJS ABI, source locations, runtime checks, and evaluation order. Current AST consumption is acceptable migration state, not architecture. Drive toward a semantic-IR emitter and retire AST walking after differential and end-to-end parity. `JsSemanticEmitter` is the semantic-IR renderer foundation that replaces the AST emitter at the atomic cutover (ISSUE-0805), with `RuntimeDeclarationSurface`/`RuntimeDeclarationProjection` as the structural declaration seam and one artifact per implementation unit from `JsEmissionInput`. The renderer emits content and coordinate-only mappings, never lowering, filesystem effects, Node execution or host/default invocation, and it fails closed on an unsupported slice instead of rerouting. Its runtime linkage (`$rt.initModule`/`moduleSurface`/`publishModule`/`readModule`/`moduleState`/`callExport`/`throwValue`, plus the carrier-neutral `tableGet`/`tableSet`/`tableDelete` index members over the Map and module-surface carriers) lives in `deal/runtime.js` and carries representation only. Avoid deepening AST-only semantics. The declared-export validation/raw-read order is the shared ascending-name selection (`HostDeclarationSurface.sortedByName`), each source HOST import owns its fresh typed surface over one raw Node require per resolved file, and the array for-of uses the shared live-position traversal (deleted-slot stop, visited contiguous appends, iterable evaluated once). Architectural direction never expands assigned task scope. Keep this file always synchronized with code.
