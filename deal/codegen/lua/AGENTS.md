# LuaJIT Backend

Emit LuaJIT artifacts from validated semantic IR while preserving Lua ABI, FFI, async, errors, and evaluation order. Extend LuaSemanticEmitter for semantics; never restore AST emission. Verify Oracle parity and real luajit execution. Carrier identity, container length, insertion order and the per-slot numeric-variant marks are keyed by the process-wide private table keys (`__dealCarrierKeys`, adopted by `deal/runtime.lua`), never by string fields: a DEAL table may carry any string key (a class field or a JSON member may be named after any of them) and a table value never forges a class, Error, bytes, function, array, async or numeric-variant carrier. Classification reads those keys only; the documented host-module authoring shapes (`__rt.function_`, `__rt.export_class`, the `{__kind, sig, f}` / `{__kind, __classname}` host exports) stay accepted at the host-load boundary and normalize into the private-marked representation. The host-crossing projection hands the raw host the declared DEAL value: the sync parameter cell, the async-argument crossing and the class-field projection unwrap a numeric-variant carrier to its number at every declared position (array elements and object members recursively, class fields in place) while the container identity, alias behavior and the per-slot numeric-variant marks are preserved, so an echoed decoded container re-encodes its own `int`/`number` spellings — the JVM boxed-carrier unwrap and the JS `$hostProjectValue` leaves. An inbound plain Lua table the raw host returned or passed at a declared `table` position is the table value: `TABLE_KEYS` takes its present string keys and `JSON_STRINGIFY` encodes its JSON-shaped content (the dense 1..n numeric form as an array, other tables as objects over their string/numeric key texts, with the recorded per-slot marks), so no raw `#nil` failure or false `E8001` arises; a table that already carries a produced carrier mark keeps its recorded order, marks and DEAL identity. An inbound plain Lua table at a declared array position is the DEAL array value only when it has the value mapping's 1-based contiguous storage (every key a positive integer, every one-based slot present, where a nullable element position's absent slot is the matcher's null admission): every host-to-DEAL crossing — the async-function completion value and the parameter entry of a DEAL callback the host invokes — runs the identity-preserving projection the synchronous host return runs (nested arrays, null elements and aliases preserved), so the body reads `.length` and the elements at every one-based slot, while a map table, a sparse table at a non-nullable element position or any other non-array table is left unprojected so the position's typed-boundary cell raises the closed kind failure instead of an emptied or truncated array. Every declared callback parameter position then runs its recorded parameter-entry cell with the supplied value or nil for an omitted argument, so a non-nullable omission fails closed and a nullable omission takes the null mapping, and a raw Lua function at a declared function position takes the closed kind row (never an internal index of the function value). A raw nil array slot is the internal missing/deleted element and never serializes as JSON null, in the emitted walk and the shipped `std/json` alike; a present object member the presence map records stays a JSON null member (the chunk's JSON_PARSE graph stores no value for it), and the shipped `std/json` parse records the same per-slot `int`/`number` variant marks the emitted prelude writes. One pair of factory-store helpers (`__factories.__hostCarrierOut`/`__hostCarrierIn`, ISSUE-0850) is the single representation-directed projection every host crossing delegates to: descriptor-directed at declared positions and value-directed at untyped positions, total, idempotent, and memoized per crossing; a chunk class carrier becomes a runtime instance with top-level declared fields and the carried identity, a dual-tagged host-class instance keeps its identity until a declared field needs re-representation and then becomes a fresh tagged copy, and a host-origin instance crosses by identity with only the landed numeric projection; inbound, a host-class instance becomes a fresh dual-tagged instance while a DEAL/extern-C identity keeps the private `__f`/`__p` carrier; the builtin `Error` carrier and its runtime instance shape map both ways; containers keep their shared identity and in-place numeric marks until a class/function/Error element or member needs re-representation and then become one memoized copy with the carrier marks, a dense host table is an `__a` carrier only at a declared array position, and a sparse/map table is left for the declared cell; a DEAL function carrier becomes the documented `{__kind = "function", sig, f}` wrapper through `__hostFnArg` with the emitted `__hostFnShapes` cells while a wrapper and a raw Lua function cross unchanged; the pair composes no DEAL failure (a missing shape entry is a plain producer diagnostic), never mutates the DEAL-side value beyond the landed in-place numeric projection, and never mutates a host-origin object.
