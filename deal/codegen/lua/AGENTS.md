# LuaJIT Backend

Emit LuaJIT artifacts from validated semantic IR while preserving Lua ABI, FFI, async, errors, and evaluation order. Extend LuaSemanticEmitter for semantics; never restore AST emission. Verify Oracle parity and real luajit execution. Carrier identity, container length, insertion order and the per-slot numeric-variant marks are keyed by the process-wide private table keys (`__dealCarrierKeys`, adopted by `deal/runtime.lua`), never by string fields: a DEAL table may carry any string key (a class field or a JSON member may be named after any of them) and a table value never forges a class, Error, bytes, function, array, async or numeric-variant carrier. Classification reads those keys only; the documented host-module authoring shapes (`__rt.function_`, `__rt.export_class`, the `{__kind, sig, f}` / `{__kind, __classname}` host exports) stay accepted at the host-load boundary and normalize into the private-marked representation. The host-crossing projection hands the raw host the declared DEAL value: the sync parameter cell, the async-argument crossing and the class-field projection unwrap a numeric-variant carrier to its number at every declared position (array elements recursively, class fields in place) while the array/object identity, alias behavior and the per-slot numeric-variant marks are preserved, so an echoed decoded array re-encodes its own `int`/`number` spellings — the JVM boxed-carrier unwrap and the JS `$hostProjectValue` leaves. Keep this file always synchronized with code.
