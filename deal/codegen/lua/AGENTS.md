# LuaJIT Backend

Emit LuaJIT artifacts from validated semantic IR while preserving Lua ABI, FFI, async, errors, and evaluation order. Extend LuaSemanticEmitter for semantics; never restore AST emission. Verify Oracle parity and real luajit execution. Carrier identity, container length, insertion order and the per-slot numeric-variant marks are keyed by the process-wide private table keys (`__dealCarrierKeys`, adopted by `deal/runtime.lua`), never by string fields: a DEAL table may carry any string key (a class field or a JSON member may be named after any of them) and a table value never forges a class, Error, bytes, function, array, async or numeric-variant carrier. Classification reads those keys only; the documented host-module authoring shapes (`__rt.function_`, `__rt.export_class`, the `{__kind, sig, f}` / `{__kind, __classname}` host exports) stay accepted at the host-load boundary and normalize into the private-marked representation. Keep this file always synchronized with code.
