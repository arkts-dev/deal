# Code Generation

Translate validated semantic IR into target representation without redefining language semantics. Preserve boundaries, evaluation order, errors, and ABI behavior. Two same-named declarations of sibling modules in one directory share one canonical class identity: the emitted JSON plan table carries the unique plan-bearing (`@jsonable`) declaration's layout with that declaring unit's own CLASS_DEFAULT ops as the plan's defaults, the plan's field defaults and nested links therefore agree with the exact construction, and the generated carrier class carries the union of the identity's declarations' field names so either declaration's construction sites find their own slots. The product goal is semantic-IR emission on every backend; extend shared contracts and retire AST-consuming emitters after parity. `JsSemanticEmitter` is the JavaScript semantic-IR renderer foundation (one CommonJS artifact per implementation unit, coordinate-only maps); it is internal until the atomic JS cutover. A detached class-default invocation is invocation-local: every emitted default saves and restores its own block's slots and cells (the shared `EmitterSessionBase.defaultBlockStateKeys` collection) around the attempt — on the success and the failure path alike — so a nested or re-entrant construction never overwrites the enclosing attempt's operands. Architectural direction never expands assigned task scope. Every production emission installs the project source-map recorder: source comments and per-source `.deal.map.json` sidecars are the v1.3 default, and the accepted `--source-map` spelling selects nothing. Keep this file always synchronized with code.
