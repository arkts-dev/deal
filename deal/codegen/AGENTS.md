# Code Generation

Translate validated semantic IR into target representation without redefining language semantics. Preserve boundaries, evaluation order, errors, and ABI behavior. The canonical class identity names the defining file, so two same-named sibling files are two identities and each emits its own layout, plan and carrier; for a carrier-shared identity (a harness-synthesized identity a valid project never produces) the emitted JSON plan table carries the unique plan-bearing (`@jsonable`) declaration's layout with that declaring unit's own CLASS_DEFAULT ops as the plan's defaults, the plan's field defaults and nested links therefore agree with the exact construction, and the generated carrier class carries the union of the identity's declarations' field names so either declaration's construction sites find their own slots; the JavaScript renderer instead keeps every declaration's layout, default owner and constructor plan per declaring unit and resolves cross-module `C$fields` reads through the plan-bearing declaration, so neither construction borrows a sibling's flattened field set. Every production backend renders semantic IR; the AST-consuming emitters are retired and no fallback route exists. `JsSemanticEmitter` is the JavaScript semantic-IR renderer (one CommonJS artifact per implementation unit, coordinate-only maps recorded through the shared `SourceMapRecorder` with local/foreign placement and one version-1 sidecar per artifact). `ProductionProjectEmission.run` selects it for `Backend.JS` as the one rendering invocation over the one lowered project, so the JavaScript production artifacts of a compile come from that single call; the public dispatch has one production arm for every backend: no AST emitter exists and no invocation purpose selects an alternate rendering (ISSUE-0805). A class-default construction attempt is invocation-local end to end: every emitted default saves and restores its own block's slots and cells (the shared `EmitterSessionBase.defaultBlockStateKeys` collection) around the attempt — on the success and the failure path alike — and every construction attempt keeps the default values it produces in attempt-local scratch (one local per attempt in Lua and the JVM alike) that its declaration-order field boundaries read, in the `LOCAL` arm and in the `SHARED_FACTORY` transfer arm, so a nested or re-entrant construction never overwrites the enclosing attempt's operands or its produced default values. Architectural direction never expands assigned task scope. Every production emission installs the project source-map recorder: source comments and per-source `.deal.map.json` sidecars are the v1.3 default, and the accepted `--source-map` spelling selects nothing. Keep this file always synchronized with code.
