# Code Generation

Translate validated semantic IR into target representation without redefining language semantics. Preserve boundaries, evaluation order, errors, and ABI behavior. Two same-named declarations of sibling modules in one directory share one canonical class identity: the emitted JSON plan table carries the unique plan-bearing (`@jsonable`) declaration's layout with that declaring unit's own CLASS_DEFAULT ops as the plan's defaults, the plan's field defaults and nested links therefore agree with the exact construction, and the generated carrier class carries the union of the identity's declarations' field names so either declaration's construction sites find their own slots. The product goal is semantic-IR emission on every backend; extend shared contracts and retire AST-consuming emitters after parity. `JsSemanticEmitter` is the JavaScript semantic-IR renderer (one CommonJS artifact per implementation unit, coordinate-only maps recorded through the shared `SourceMapRecorder` with local/foreign placement and one version-1 sidecar per artifact). `ProductionProjectEmission.run` selects it for `Backend.JS` as the one rendering invocation over the one lowered project, so the JavaScript production artifacts of a compile come from that single call; the public dispatch keeps the retained AST arm until the atomic cutover (ISSUE-0805). A class-default construction attempt is invocation-local end to end: every emitted default saves and restores its own block's slots and cells (the shared `EmitterSessionBase.defaultBlockStateKeys` collection) around the attempt — on the success and the failure path alike — and every construction attempt keeps the default values it produces in attempt-local scratch (one local per attempt in Lua and the JVM alike) that its declaration-order field boundaries read, in the `LOCAL` arm and in the `SHARED_FACTORY` transfer arm, so a nested or re-entrant construction never overwrites the enclosing attempt's operands or its produced default values. Architectural direction never expands assigned task scope. Every production emission installs the project source-map recorder: source comments and per-source `.deal.map.json` sidecars are the v1.3 default, and the accepted `--source-map` spelling selects nothing.
