# Native LLVM Code Generation

Render the one validated lowered project as one deterministic textual LLVM module (`deal.codegen.llvm.LlvmSemanticEmitter`), and let `deal.module.ProductionProjectEmission` stage it plus the closed `NativeRuntime.FILES` set. Consume only `ExecutableLoweredProject` with its body tables, factory registries and declaration facts: never an AST, a checker object, or a native-only language rule. Keep the closed-set classifier authoritative: every operation kind, payload variant, selector, boundary kind, stdlib operation, failure arm, control selector, call mode, target kind and module-import kind carries exactly one decision in `LlvmStageClassifier`, and a fact outside the staged scalar skeleton raises one `SharedEmissionFailure` with that operation's own origin, which the production arm projects as the single E6005 `SHARED_EMITTER_COVERAGE`. Render only the permitted external references: the call-frame and root-frame prologue/epilogue entries, the emitted arm table and its install entry. Every generated activation pushes its frame label, enters a zero-slot root frame, and leaves and pops on every exit path; managed values, allocating calls, runtime-service calls and failure materialization wait for their own children, so the staged subset renders no root slot write. Keep `LlvmRuntimeAbi` the single Java mirror of the published headers, in the published declaration order, with `LlvmTypeMapper` the one C-to-IR and descriptor-to-representation mapping and the one pointer-type constructor; a new runtime entry extends the mirror in the same change. Emit the closed failure-arm table as data in the published `deal_arm_record`/`deal_arm_table` layout, in the registry's canonical order, and install it in `deal_project_start` before any unit's initialization. The module owns `deal_module`, `deal_export_entry` and the six export-surface definitions, defines no process entry and no runtime-owned symbol, and carries the pinned triple, both debug names per function and project-relative file names. Derive every name, order and record from IR facts: no map iteration order, timestamp, absolute path or environment text reaches the bytes.
