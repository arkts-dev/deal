# Native LLVM Code Generation

Render the one validated lowered project as one deterministic textual LLVM module (`deal.codegen.llvm.LlvmSemanticEmitter`), and let `deal.module.ProductionProjectEmission` stage it plus the closed `NativeRuntime.FILES` set. Consume only `ExecutableLoweredProject` with its body tables, factory registries and declaration facts: never an AST, a checker object, or a native-only language rule. Keep the closed-set classifier authoritative: every operation kind, payload variant, selector, boundary kind, stdlib operation, failure arm, control selector, call mode, target kind and module-import kind carries exactly one decision in `LlvmStageClassifier`, and a fact outside the staged scalar skeleton raises one `SharedEmissionFailure` with that operation's own origin, which the production arm projects as the single E6005 `SHARED_EMITTER_COVERAGE`. Render only the external references the emitted facts need, each one published by `LlvmRuntimeAbi`: the call-frame and root-frame prologue/epilogue entries, the emitted arm table and its install entry, the one string comparison (`deal_text_compare`), the closed data relation (`deal_data_same`), the two nullish singleton predicates, the type-name projection and the descriptor-driven check. Every generated activation pushes its frame label, enters its root frame with the statically known slot count, and leaves and pops on every exit path; every managed-typed slot that can be live across an allocating call owns one root slot written at definition (a persistent datum through the tag-aware entry, a managed pointer directly, a reference-nullish operand only when it is no nullish singleton), and a scalar or code-pointer slot owns none. Keep `LlvmRuntimeAbi` the single Java mirror of the published headers, in the published declaration order, with `LlvmTypeMapper` the one C-to-IR and descriptor-to-representation mapping, the one pointer-type constructor and the one record-size rule that decides when a published record crosses the C ABI through a hidden `sret`/`byval` pointer; a new runtime entry extends the mirror in the same change. `LlvmSelectorArms` is the single rendering authority of the closed binary and unary selector families: one arm per merged member, with C6's pinned IEEE predicates, the one string-comparison authority, the distinct nullish singleton/tag tests, the closed data relation, managed identity, `fneg`, `xor i1`, the type-name projection and the nominal tag test, and no fast-math flag on any instruction; every runtime-entry arm carries that entry's own result encoding, so `deal_text_compare`'s `-1`/`0`/`1` ordering is compared against zero with the selector's predicate while `deal_data_same`'s `1`-when-equal truth is compared against zero with the inverted one. A `BRANCH` over the logical selectors enters the recorded right-operand block on true for `LOGICAL_AND` and on false for `LOGICAL_OR`, keeps the left operand's value as the skipped path's result, and every rendered call or import tests its carried Error explicitly so the continuation stays reachable. Every failure path returns the enclosing activation's own C4 outcome shape, derived from the lowered function that path belongs to: a `number`, `boolean`, scalar-nullish or `unknown` result keeps its value slot empty on failure instead of degrading to the error-only aggregate, and a returned outcome slot is narrowed back to the SSA spelling only for the managed pointer shapes whose SSA type differs (a `string` and a class instance's own typed record pointer, the builtin `Error` included), because a scalar-nullish aggregate, a reference nullish pointer, a `double`, a persistent datum and a code pointer are already their own slot type. A value whose C3 representation this stage does not construct is never admitted into a position that would need it: a function value is the managed `deal_fn*` closure carrier of C5, so `LlvmTypeMapper.admits`/`convertible` reject it at every `unknown` position (declaration, assignment, parameter, return, import/export) as the boundary's own origin-bearing E6005 instead of publishing a `deal_data` whose managed tag would hold a `.text` address — and the function-tagged datum the `typeof` projection builds carries only its tag, with a NULL `reference`, exactly as `deal/native/value.h` requires (the `reference` member is the managed payload for the managed tags and always NULL otherwise). Each binding's declared descriptor comes from the `VARIABLE_DECLARATION`/`VARIABLE_ASSIGNMENT` boundary the lowering emits between that write's value and its commit op, resolved per write and never from a bare value id: the lowering reuses a function-valued identifier's value id for its `BINDING_LOAD`, so a value-keyed lookup would give one binding another binding's declared type. A refined read of that binding projects the value it actually holds onto the refined type's representation through the one datum authority and validates it against the refined descriptor at the read's own origin, so a stale refinement fails with the declared E8001 arm instead of yielding a base value the binding never held. A structure op whose recorded child paths all return or throw leaves its join without a predecessor: render that tail as `unreachable` and emit no fall-through epilogue, never an E6005 for a valid program. Emit the closed failure-arm table as data in the published `deal_arm_record`/`deal_arm_table` layout, in the registry's canonical order, and install it in `deal_project_start` before any unit's initialization. The module owns `deal_module`, `deal_export_entry`, the two scalar nullish representations and the six export-surface definitions, defines no process entry and no runtime-owned symbol, and carries the pinned triple, both debug names per function and project-relative file names. Derive every name, order and record from IR facts: no map iteration order, timestamp, absolute path or environment text reaches the bytes. A string literal is immutable static data copied by the `text` group into one runtime string, a template concatenates its recorded fragments in order, and every managed temporary the op itself creates is stored in an activation scratch slot and rooted before the next allocating call. Containers render the `container` group's typed array and insertion-ordered record: `ARRAY_NEW` allocates the array with its persistent element descriptor and appends its validated elements, an index read/write validates finiteness, integrality and bounds through `deal_container_position` before any native offset conversion (a rejected position is the named E8002 arm at the recorded boundary's origin, negative zero addresses zero, and an append commits only after the element check), `length` is the exact count as binary64, a record keeps absence distinct from present-undefined and present-null, and `FOR_EACH` retains its once-evaluated iterable and re-reads the live element count, its live element and its iteration binding at every step (a string traversal yields one single-scalar string per scalar). A declared `null`/`undefined` position is a value of its own type, never an absent slot: a field or array element of those types is one reference slot holding the distinct runtime singleton (the `null|undefined` union is that same singleton slot, and its undefined member is admitted through the atom's own base), so class construction, field read/write/delete, array construction/element access, `FOR_EACH` and the JSON construct/read seams all materialize or store the singleton the shared representation names; the optional-read absence projection answers `undefined` whenever the read type admits it, including that canonical union. Each declared class emits one typed instance record (class atom, one presence byte per optional field, one typed slot per declared field), one published `deal_layout` in the emitted install table, one `deal_class_layout` whose field descriptors are the interned atoms, and one `deal_json_class_plan` with its `construct` and `read_field` seams; `deal_class_plans_init` installs the layout table and fills the atoms from `deal_project_start` before any unit initialization. A local class construction validates its supplied fields in literal order through `deal_class_construct` and allocates, tags and publishes the instance only after every check succeeded, the builtin `Error` construction is `deal_error_create_strings` so the constructed instance is the runtime's own record, and a field read projects optional absence to undefined through the presence byte without erasing it (a declared `unknown` field absorbs the nullish members, so its read type is the persistent datum: the present arm stores the loaded `deal_data` slot and the absent arm the undefined datum, and no optional read has a result type without an absence projection). The emitted reference map names the slot itself for a managed-pointer slot and the datum's own `reference` member (`offsetof(deal_data, reference)`) for an `unknown` slot, never the tag word that slot starts with, so the precise collector traces the stored referent and never `tag`/`reserved` bits; every store into such a slot — at construction, in the JSON `construct` seam and at every later field write — runs the published insertion barrier on the committed slot (`deal_store_barrier` for a pointer slot, the tag-aware `deal_store_barrier_data` for a persistent datum), keeping the traced reference map and the M2 barrier contract in agreement. The generated `C$fromJson`/`C$toJson` walks call the runtime JSON group with the emitted plan and the emitted plan lookup, so the runtime keeps the declaration-order walk, the extra-key/missing-required rules, the cycle check and every failure projection. `LlvmDataValues` is the one native-to-`deal_data` conversion in both directions (branchless, tag-driven, the class atom of a class datum is its instance's own atom, and a builtin `Error` value's managed payload is the `deal_error*` it already holds because the module defines no per-layout record for it), and the export record publishes a code pointer only for the zero-arity synchronous value shape the entry surface can invoke.
