# JVM Backend

Emit valid JVM artifacts from validated semantic IR and keep runtime identity, host, async, and boundary behavior exact. Extend JvmSemanticEmitter for semantics; never restore AST emission. Keep the shared JvmNames naming surface single-sourced. Verify Oracle parity and real javac/java execution. Declared host classes construct from provided, boundary-validated fields and never reflect a `<C>_defaults` export. Required omissions reject, including both builtin Error fields; nullable does not imply optional. Numbers and raw array-slot trace indexes use binary64; slot atoms use canonical hexadecimal spelling, never boxed-kind or decimal-format inference. ASSERTION preserves the admitted identity and projects mismatches through the E8001 typed-kind arm at the assertion origin, including signature and nested-array mismatches. Missing and undefined publish the undefined diagnostic kind, not nil. Host Record mismatch reasons consume canonical record to render diagnostic table, never feed table back into the descriptor parser. Host admission independently handles null and undefined flags, translates missing to undefined, and admits unknown/void through their shared checks. Host projections preserve undefined sentinel identity before number/array/function conversion and strip both nullish prefixes. In-range deleted array reads return UNDEFINED independently of element nullability; a nullable element descriptor never turns an absent slot into null. Trace atoms recognize undefined and Error carriers before declared-kind dispatch: an Error held as unknown keeps the Oracle's error atom without consuming a heap allocation ID. Generated JSON decoding sets the exact runtime-dialect persistent element descriptor on every typed array, including empty/nested arrays and independently nullish elements. Unknown ingress validates string scalars and rejects foreign JVM objects with a DEAL kind failure, never a caller's arbitrary static-kind token. Reentrant synchronous and async invocations share per-body snapshot/restore helpers with bounded copier chunks, not call-site-expanded state arrays. Saves remain unconditional and restores run on every finally path, preserving cell references, enclosing activation state and active markers without semantic trace events. Large synchronous factory bodies split only between whole top-level semantic operations into detached methods with explicit capture parameters; return transfers unwind to the factory without extra trace events or frames. Loops and protected handlers remain whole, preserving label scope, transfer closures and failure causes; this does not bound a single arbitrarily large structured operation. Source-map recording follows final helper placement. The segmentation prepass must not mask owning-operation guard diagnostics with a missing-child null dereference. Resultless core-window and segmented fallthrough publish JvmRuntime.UNDEFINED, never Java null. Host-boundary plans consume canonical record descriptors while diagnostics retain table; never admit table as a descriptor alias. Verify real javac/java with wide repeated-call and recursive sync/async bodies, captured cells, loop transfers and protected returns; emitted-source size alone is not evidence. std/json stringify uses generated declaration-order fieldNames on ClassInstance (including host carriers), presence-aware reads and a stack-safe class frame over the original identity. Error serializes code/message only; transport fields never leak, and class cycles take the ordinary cycle arm. Published async-export JSON uses these same rules, including null substitution for nonfinite numbers and array holes/functions; roots without JSON representation fail as representation failures before envelope serialization.
