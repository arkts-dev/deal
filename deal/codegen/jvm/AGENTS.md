# JVM Backend

JvmSemanticEmitter/JvmNames render validated IR, never ASTs. Execute boundary/host/async identity via javac/java; normalize native failures. Distinguish null/missing/UNDEFINED; resultless bodies return JvmRuntime.UNDEFINED. Preserve sentinels before projection. Segment whole operations; finally preserves recursion/captures/transfers/frames/maps/diagnostics. Function carriers save/restore their own activation slots at entry/exit, including dynamic, adapter, host and async invocation; restore cell references, never undo live captured-cell mutations. Large closures partition static storage and function factories/snapshots into nested classes in the same Java artifact to avoid class-wide constant-pool overflow; preserve qualified access, source maps, initialization and sync/async re-entry. Class JSON preserves private order/presence/cycle identity; Error exposes code/message only. Records share JSON rules; parsed projection: stack-safe. For-of traversal temporaries carry their operation id, including inside lambdas; Java locals cannot shadow enclosing loop locals. Preserve host identities/aliases/array descriptors; cache bridges. Validate class/Record/unknown graphs before publication: complete declaration plans, operation-local identity/descriptor guards, valid callable payloads/signatures including unread descendants. Host Unicode uses closed reasons, never blanket catches.
