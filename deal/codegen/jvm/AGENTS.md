# JVM Backend

Render validated IR with JvmSemanticEmitter/JvmNames, never AST emission. Execute boundary/host/async identity via javac/java; normalize native failures. Distinguish null/missing/UNDEFINED; resultless bodies return JvmRuntime.UNDEFINED. Preserve host sentinels before projection. Segment whole operations only; restore recursive state in finally without changing captures/transfers/frames/maps. Preserve owning-operation diagnostics. Class JSON uses private declaration order/presence and original cycle identities; Error exposes code/message only. Generated Records share generic omission/substitution/own-key ordering. Preserve original host identities, live aliases and persistent array descriptors; validate class/Record/unknown graphs before publication; cache bridges. Nominal checks consume complete declaration field plans and operation-local identity/descriptor guards. Invalid native callable payloads/signatures reject even in unread descendants; malformed host Unicode uses the closed host reason projection, never a blanket producer-defect catch.
