# Project Configuration

Own strict manifest parsing, project discovery, roots, outputs, and external declarations. Validate before overrides or output creation. Normalize paths once while preserving configured identity where required. Require the specification's languageVersion and matching stdlib (the default when absent); reject other manifest versions before publication. Keep one backend name authority across the CLI alias set, the manifest validator, the default-output table and the compile pipeline, so the accepted names and their rejection texts never disagree. Source/declaration directives cannot select a version. Configuration failures remain deterministic and publish nothing. Keep this file always synchronized with code.
