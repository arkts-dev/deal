# Modules

Own resolution, dependency order, checked-project orchestration and identity assembly. Validate the complete graph before lowering or publication; preserve deterministic phase order. Isolated constructors use the same active version constants as project discovery. Preserve DistributionHome precedence: project-local stdlib, packaged resources/home, then checkout fallback; runtime files exclude project overrides.

Carry exact declaration/provider facts through imports, annotations, contextual literals, call results and inferred carriers. A same-spelled local or sibling declaration cannot capture another provider's layout. Canonical nominal identity names the defining file; reject unrepresentable identities and distinct-provider crossings rather than retagging values. Whole-project provider indexes resolve declarations reached indirectly through fields, parameters and results.

Class plans contain structural fields only: name, descriptor and optional flag. Annotations create no executable initializer/default dependencies. Preserve ordinary function-body dependency discovery, resource ranges and provider digests. Consume TypeChecker's single definite-return decision; no secondary null-falloff walk or recursive-group exception.

ProductionProjectEmission owns one project lowering, closure guard and rendering per target. JS stages one CommonJS artifact and version-1 sidecar per implementation unit; LuaJIT/JVM/LLVM render one project artifact, and the LLVM arm additionally stages the closed C11 runtime deployment set with no sidecar. The returned entry path and produced project belong to that invocation. No purpose flag, retained backend, retry or AST fallback selects another renderer.

Stage generated artifacts, maps, dumps and required runtime/stdlib copies in one transaction. Missing resources fail compilation; rejection publishes nothing. Source comments/maps are the default, and --source-map selects no alternate behavior. Keep responsibilities synchronized without policy inventories.
