# Lexer

Produce tokens, directives, and exact Unicode-scalar spans with deterministic recovery. Delegate position arithmetic to source utilities. Encode syntax only; multiline template tokens retain physical raw text through closing backticks. Decode CR/CRLF as LF and escaped line continuations as empty text; reject malformed TypeScript numeric/hex/Unicode escape spellings without decoding token text. Ordinary strings decode the specified character, hexadecimal-unit and Unicode escapes once, preserving lone UTF-16 units; malformed/out-of-range spellings reject. Adjacent minus characters reject rather than becoming two operators. Update lexer, parser, and diagnostic tests together. Project manifests alone own language versions; source has no version directive or version AST metadata. Keep policy synchronized.
