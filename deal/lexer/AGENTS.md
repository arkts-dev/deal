# Lexer

Produce tokens and exact UTF-16 source spans with deterministic recovery. Comments are whitespace regardless of their contents; never interpret @ names, arguments or placement, and never emit directive events or diagnostics. Delegate position arithmetic to source utilities. Encode syntax only; multiline template tokens retain physical raw text through closing backticks. Decode CR/CRLF as LF and escaped line continuations as empty text; reject malformed TypeScript numeric/hex/Unicode escape spellings without decoding token text. Ordinary strings decode the specified character (including b/f/v/0), hexadecimal-unit and Unicode escapes once, preserving lone UTF-16 units; LF/CR/CRLF continuations contribute no text and retain physical coordinates. Reject decimal digits after a zero escape and malformed/out-of-range spellings. Numeric tokens admit decimal trailing points, binary/octal/hex prefixes and separators only between digits of the active radix; reject adjacent identifier suffixes and malformed exponents with deterministic recovery. Tokenize ?? by longest match while retaining a standalone ? for conditionals. Adjacent minus characters reject rather than becoming two operators. Update lexer, parser, and diagnostic tests together. Project manifests alone own language versions; source has no version directive or version AST metadata. Keep policy synchronized.
