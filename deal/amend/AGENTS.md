# Amend

Client-facing amendment of checked DEAL source. Two entry paths: direct (`applyChecked`, one ChangeSet, commit or reject) and scoped repair (`stageChange`, `expandRepairScope`, `applyRepairTransaction`, per-slot, grant-limited). Edits are revision-pinned; a target requires the fingerprint from `inspect` or `inspectChange`. Identities are compiler-issued, revision-scoped, never persisted, never written to source. `ModuleResolver`, `SourceAdapter`, and `CandidateValidator` are the seams; consumer framework checks enter through `CandidateValidator` inside the transaction. Scope is one module, front end only: never invoke the project orchestrator, never claim the project builds. Emitted source is a candidate; the checker stays authoritative. Keep this file synchronized with code.
