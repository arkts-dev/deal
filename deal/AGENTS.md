# Compiler

Own compiler phases, runtimes, and CLI integration. `deal/runtime.lua` keys every carrier identity, container length and numeric-variant mark by the process-wide private table keys `__dealCarrierKeys` (shared with the emitted chunks), so a user table's string keys never select or forge a carrier; the documented host-module shape stays accepted at the host-load boundary and is normalized into that representation. Runtime surfaces this file's phases own are checked against the same closed keys, and every typed-boundary failure the runtime raises publishes the closed typed-boundary actual token (`__rt.typed_kind`) — a class instance's carried canonical class atom (exactly `Error` for the builtin), `array`, `bytes`, `function`, `null`, `nil`, or a numeric-variant carrier's own recorded `int`/`number` token — never the raw Lua `type()`, so the shipped runtime/stdlib tuples match the emitted prelude, JVM and JS consumers. A numeric-variant carrier (`{[__dealCarrierKeys.jn] = true, k, d}`) is the value it stands for at every numeric boundary: `check_int` admits the int variant and runs the refinement/signed32 ladder for the number variant (NaN, infinity, non-integer, then `E8004`) while preserving the carrier and its recorded variant, and `check_number` admits both variants — the same admission the emitted prelude's int/number cells, the JVM runtime's boxed `Long`/`Double` rows and the JS `checkInt`/`checkNumber` apply. The number a closed arm's actual spells is rendered by one canonical hex-float spelling per consumer (`__rt.number_hex`, the JS `numberHex`, the prelude's `__numHex`, the JVM `Double.toHexString`, the shared `CanonicalJson#numberHex`), never a local `tostring`/`String` composition. A call-preserved null-narrowing refinement is a claim about a mutable binding, so the one lowering validates a refined identifier read at every operator operand, condition, index receiver/key, table member receiver and `.length` receiver position (`NARROWED_READ`, the read's own origin and refined descriptor) while every typed boundary keeps its own recorded projection: no backend coerces a cleared binding, folds it into a boolean, or lets a raw arithmetic/index error escape a DEAL `try`; an address chain and a table member read/write/delete consume the admitted receiver/key, a `.length` read consumes the admitted receiver, never the unadmitted read, and a slot-threading consumer keeps its one identity (the logical-right operand of an `if`/`while`/`for` condition republishes that condition, so the `LOOP(FOR)` condition is the logical result and never the raw read alone). Preserve specification semantics, deterministic diagnostics, and transactional publication. Checked facts lower into backend-neutral semantic IR; every production backend renders that IR and no AST emitter remains. Put semantics before emission and verify affected phases. Keep this file always synchronized with code.
