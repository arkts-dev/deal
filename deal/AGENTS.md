# Compiler

Own compiler phases, runtimes, and CLI integration. `deal/runtime.lua` keys every carrier identity, container length and numeric carrier mark by the process-wide private table keys `__dealCarrierKeys` (shared with the emitted chunks), so a user table's string keys never select or forge a carrier; the documented host-module shape stays accepted at the host-load boundary and is normalized into that representation. Runtime surfaces this file's phases own are checked against the same closed keys, and every typed-boundary failure the runtime raises publishes the closed typed-boundary actual token (`__rt.typed_kind`) — a class instance's carried canonical class atom (exactly `Error` for the builtin), `array`, `function`, `null`, `undefined` (including private missing sentinels), or `number` for every numeric carrier — never the raw Lua `type()`, so the shipped runtime/stdlib tuples match the emitted prelude, JVM and JS consumers. The sole numeric type is binary64 `number`. Numeric boundaries preserve negative zero, NaN and infinities without conversion or signed32 refinement. Integral positions reject nonfinite or fractional inputs before storage access; never truncate. JSON parsing rounds to binary64 and preserves negative zero; stringification emits zero for either sign. `int` and `number` are ordinary value identifiers, not conversion intrinsics. The number a closed arm's actual spells is rendered by one canonical hex-float spelling per consumer (`__rt.number_hex`, the JS `numberHex`, the prelude's `__numHex`, the JVM `Double.toHexString`, the shared `CanonicalJson#numberHex`), never a local `tostring`/`String` composition. A call-preserved null-narrowing refinement is a claim about a mutable binding, so the one lowering validates a refined identifier read at every operator operand, condition, index receiver/key, table member receiver, `.length` receiver, for-of iterable and Object.hasOwn receiver position (`NARROWED_READ`, the read's own origin and refined descriptor) while every typed boundary keeps its own recorded projection: no backend coerces a cleared binding, folds it into a boolean, or lets a raw arithmetic/index error escape a DEAL `try`; an address chain and a table member read/write/delete consume the admitted receiver/key, a `.length` read consumes the admitted receiver, a for-of loop consumes the admitted iterable before its initialization dereferences the carrier and an Object.hasOwn presence read consumes the admitted receiver (the refined class descriptor's nominal check), never the unadmitted read, and a slot-threading consumer keeps its one identity (the logical-right operand of an `if`/`while`/`for` condition republishes that condition, so the `LOOP(FOR)` condition is the logical result and never the raw read alone). Class construction uses structural declaration-order plans and supplied values only. Required nullable fields still require presence; optional omissions stay absent. Runtimes expose no defaults-copy constructor and never consult legacy evaluator metadata. Preserve specification semantics, deterministic diagnostics, and transactional publication.
