# Checker

Own resolution, typing, narrowing, and explicit checked facts. Diagnostics and fact production must be deterministic and target-neutral. Expose every fact semantic lowering needs; emitters must not rediscover source meaning. An import alias carries its module's own declared class symbols, so a qualified annotation's construction context, field access, delete target and has check read the alias's exact declaration, never a same-spelled local declaration, a textual class-name search or an identity-first alias. Every class-typed expression (identifier bindings, class-typed fields, array-of-class reads, constructed literals) publishes its exact declaring declaration through the checked result, so the one lowering selects the exact declaring provider of a field operation instead of re-resolving a name or an ambiguous canonical identity. Test accepted and rejected forms. Record ordinary function-expression body scopes in module-level class defaults before checking their local bindings; this does not admit local class declarations. Keep this file always synchronized with code.
