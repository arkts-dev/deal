# Checker

Own resolution, typing, narrowing, and explicit checked facts. Diagnostics and fact production must be deterministic and target-neutral. Expose every fact semantic lowering needs; emitters must not rediscover source meaning. An import alias carries its module's own declared class symbols, so a qualified annotation's construction context, field access, delete target and has check read the alias's exact declaration, never a same-spelled local declaration, a textual class-name search or an identity-first alias. Every class-typed expression (identifier bindings, class-typed fields, array-of-class reads) publishes its exact declaring declaration through the checked result. A constructed literal publishes its exact declaration only when an explicit construction context named it — the enclosing annotation, the callee parameter (resolved through the imported module's own declared function symbol and the parameter's own annotation in the callee's declaring module), or the current function's declared return annotation — so a same-identity sibling never captures the construction and a literal without such a context publishes nothing (the one lowering then refuses a multiple-declaration identity instead of masking it with a unit-local declaration). The one lowering selects the exact declaring provider of a field operation and attributes a literal's resources to its own construction declaration instead of re-resolving a name or an ambiguous canonical identity. Test accepted and rejected forms. Record ordinary function-expression body scopes in module-level class defaults before checking their local bindings; this does not admit local class declarations. Keep this file always synchronized with code.
