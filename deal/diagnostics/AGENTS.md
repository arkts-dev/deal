# Diagnostics

Own stable compiler diagnostics and structured rendering. Codes, severity, ranges, notes, ordering, and serialized bytes are observable contracts. Use canonical source-range facilities; never leak raw exceptions. Test malformed inputs and deterministic ordering. Responsibility names the known rejected contract, not inferred blame; shared runtime codes cannot establish host responsibility. Use `docs/diagnostics-protocol-v3.md` as the diagnostic wire authority. Retain source snapshots during analysis; serialization never rereads files or reruns failures. Causal associations require a producer-owned typed event in the same source revision.
