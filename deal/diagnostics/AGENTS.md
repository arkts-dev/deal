# Diagnostics

Own stable compiler diagnostics and structured rendering. Codes, severity, ranges, notes, ordering, and serialized bytes are observable contracts. Use canonical source-range facilities; never leak raw exceptions. Test malformed inputs and deterministic ordering. Responsibility names the known rejected contract, not inferred blame; shared runtime codes cannot establish host responsibility. Retain omitted inventories at their producer; bounded detail pages use immutable inventory identities and never repeat the failed operation. Transport inventory descriptors, not unbounded retained storage.
