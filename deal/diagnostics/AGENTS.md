# Diagnostics

Own stable compiler diagnostics and structured rendering. Codes, severity, ranges, notes, ordering, and serialized bytes are observable contracts. Use canonical source-range facilities; never leak raw exceptions. Test malformed inputs and deterministic ordering. Responsibility names the known rejected contract, not inferred blame; shared runtime codes cannot establish host responsibility. Retain omitted inventories at their producer; bounded detail pages use immutable inventory identities and never repeat the failed operation. Transport inventory descriptors, not unbounded inline storage. CLI detail sidecars retain only producer inventories; bounded retrieval reads the matching sidecar without touching sources or rerunning failures. Compilation batches identify exact consumed source snapshots, including empty diagnostic results; never reread files to reconstruct them or imply discovery completed. Causal identities require a producer-owned typed event in the same source revision; absent or ambiguous causes remain null, never grouped by code, prose or proximity.
