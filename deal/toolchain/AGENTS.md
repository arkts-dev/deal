# Toolchain

The product-owned JDK-only seam between published native artifacts and the pinned external toolchain. `NativeRuntime` holds the closed ordered C11 runtime deployment set: it is the sole runtime file-list authority, every name resolves through `DistributionHome.resolveRuntimeSource` (never a project-local tier), and a missing file is the pinned `Runtime library not found: <path>` result. Keep this constant, `tools/build-release.sh`'s packaging list and the C files under `deal/native/` synchronized in one change; the generated scratch registry and driver units are never part of the set. The package name is `deal.toolchain` because `native` is a reserved Java keyword — the class names and the closed constant are the contract, not the package spelling. This package depends on the JDK and the distribution resolver only; it never depends on the emitter, orchestrator or parser.
