# C11 runtime

The published native runtime. `deal/native/deal_rt.h` is the one ABI declaration authority: it carries the canonical host-abi record set unchanged (field order, enum discriminants, signatures, registry externs and the count-zero sentinel), the error-first outcome family, the `deal_origin` transport record and the opaque runtime representations, and it reaches every service group header in dependency order. Generated code includes only this header; it never includes an internal structure. `deal_module` and `deal_export_entry` are incomplete types in every runtime translation unit — their layout exists only in the emitted project module, so no header, group or helper may define, allocate, size, fill or read them. Each service group is one translation unit plus its header, every operating-system call lives in `platform.c` alone and the overflow-checked size arithmetic of every size that reaches the platform allocator (`deal_platform_checked_add`/`_multiply`/`_round`) lives there beside it, so an allocation's header-and-payload total, its alignment, a page round and a completion payload's growth are the one deterministic resource fault when they cannot exist instead of a wrapped short region, and every published unit must compile under `-std=c11 -Wall -Werror -Wextra -pedantic` at `-O0` and `-O2`. Compose failure text never in C: the runtime materializes failures from the emitted closed arm table, which the module installs through `deal_arm_table_install` before any user code, and a structurally invalid table is one deterministic stderr line and exit 2. Constructed Errors bind origin/frames once at first throw; transported Errors retain identity/origin/frames. Snapshots are innermost-first; absent fields stay absent. Resource and invariant faults reuse `deal_platform_fault` — the only spelling — and are never language-visible `Error`s. Completion frames are platform memory with copied bytes: no managed pointer and no error token, exclusive producer ownership before publication, exactly-once consumer release, one consumer, and release/acquire publication. A layout whose payload holds managed references outside its fixed reference map registers its own resumable walk with `deal_layout_trace_register` at its first use (the `container` group walks an array's element storage that way: each call visits at most the caller's reference budget and answers the position to resume at, so one wide array is traced across several safepoints), so the collector never derives another group's layout or element stride and no slice is unbounded by object count. Exactly one collection configuration exists: allocation always runs the safepoint, the growth policy starts and advances cycles without an explicit call, and the collected runtime has no staged or selectable non-collecting mode.
