# C11 runtime

The published native runtime. `deal/native/deal_rt.h` is the one ABI declaration authority: it carries the canonical host-abi record set unchanged (field order, enum discriminants, signatures, registry externs and the count-zero sentinel), the error-first outcome family, the `deal_origin` transport record and the opaque runtime representations, and it reaches every service group header in dependency order. Generated code includes only this header; it never includes an internal structure. `deal_module` and `deal_export_entry` are incomplete types in every runtime translation unit — their layout exists only in the emitted project module, so no header, group or helper may define, allocate, size, fill or read them. Each service group is one translation unit plus its header, every operating-system call lives in `platform.c` alone, and every published unit must compile under `-std=c11 -Wall -Werror -Wextra -pedantic` at `-O0` and `-O2`. Compose failure text never in C: the runtime materializes failures from the emitted closed arm table, which the module installs through `deal_arm_table_install` before any user code, and a structurally invalid table is one deterministic stderr line and exit 2. Errors keep one identity and one immutable origin, snapshots are innermost-first, and absent error fields are reported absent, never as empty strings. Resource and invariant faults reuse `deal_platform_fault` — the only spelling — and are never language-visible `Error`s. Completion frames are platform memory with copied bytes: no managed pointer and no error token, exclusive producer ownership before publication, exactly-once consumer release, one consumer, and release/acquire publication. Every entry-surface symbol has exactly one definition per build shape: the module owns the six export-surface functions and its arm table, `entry.c` owns the terminal, `error.c` owns the accessors, the call-frame stack and the Error record's platform-storage reclamation hook, `memory.c` owns the managed object header and layout registry, the allocation entry and its safepoint, the precise non-moving incremental mark/sweep collector (mark state, bounded gray work list, the atomic-phase rescan of every root source, the sweep cursor, the size-class free lists, the `deal_gc_collect_full`/`deal_gc_statistics` entries and the timing-only `DEAL_GC_STRESS` switch), the insertion barrier, the root frames (including the zero-slot frame the emitted skeleton pushes: a frame with no slots touches no slot storage and forms no pointer from the possibly unallocated slot table), the scoped runtime roots, the registered root sources, the static root table and the captured-binding cells, `value.c` owns the nullish singletons, the persistent tagged datum, the scalar-nullish tags and the crossing value table, `text.c` owns the immutable UTF-8 storage and the one Unicode scalar-sequence comparison, `container.c` owns typed array and insertion-ordered record storage with the checked discrete-position conversion and the array's recorded persistent element descriptor, `descriptor.c` owns the canonical descriptor atom parser and its interned atoms, the closed actual-kind classification, the `typeof` six-name projection over the persistent datum tag (its six immutable names created once and registered as static roots), the one descriptor-driven check with its closed boundary kinds, the typed-boundary token projection and the class construction validation half, `error.c` owns the compiled closed arm repertoire the install entry validates against and the arm materialization that instantiates each installed arm's own template, the E8002 array-position projections, the canonical hex-float text of a numeric arm actual, the host-authored text channel and the unchanged admission of a carried Error, `json.c` owns the strict RFC-8259 scanner with its one-based UTF-8 byte positions and decoded-key duplicate rejection, the binary64 numeric-token decode, the stack-safe decoder and encoder with path-local cycle detection, an open frame that keeps only its parent link and one segment so a dotted/indexed walk position is materialized solely at a failure (scratch linear in depth), and the v1.5 own-key order, the generic `std/json.stringify` rules and the two emitted-class walk drivers whose field validation is the delivered `deal_check_value` at the JSON field boundaries, `std.c` owns the closed eighteen-operation dispatch with its `STDLIB_PARAMETER`/`STDLIB_RETURN` crossings, the Unicode scalar string operations, record keys, the four `math` operations computed without libm (the pinned flag list links none) and the platform realtime clock, and `main.c` owns the product build's process entry. A managed object's payload is preceded by a runtime-private header; no published header declares an object header, an offset or a size of one, and `deal_data`/`deal_layout` are the only structural value records (their `reference` and `reference_offsets` members carry the precise map the collector walks). Rooting is precise: every root source enumerates managed referents only, so a nullish singleton, a scalar payload and a crossing handle are never traced as heap addresses. A layout whose payload holds managed references outside its fixed reference map registers its own walk with `deal_layout_trace_register` at its first use (the `container` group walks an array's element storage that way), so the collector never derives another group's layout or element stride. A layout whose payload owns platform storage beside the managed heap registers one reclamation hook with `deal_layout_release_register` at its first use (the `error` group releases a reclaimed Error's copied code, message and origin text, its optional expected/actual text and its frames array with one duplicated label per frame that way), and the sweep runs the hook while the payload is still intact, so reclaiming a record strands no platform storage. Exactly one collection configuration exists: allocation always runs the safepoint, the growth policy starts and advances cycles without an explicit call, and the collected runtime has no staged or selectable non-collecting mode. Later children extend these files and this header set; they never redefine a delivered entry.
