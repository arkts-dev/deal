# Tests

Assert product behavior, regressions, and production paths—not governance state. Prefer minimal deterministic fixtures and exact failures. New semantics require lowerer, validator, Oracle, and backend parity coverage. Retire legacy-only assertions with AST emitters. Run focused tests first. Architectural direction never expands assigned task scope. Keep this file always synchronized with code. Register executable suites in `tools/gate-manifest.sh`; the test and coverage runners execute the same selection. Keep shared helpers and corpus fixtures needed by those suites; do not pin the existence or prose of deleted suites.
