# Runtime Conformance

Assert observable values, effects, errors, source origins, identity, and evaluation order across applicable backends. A class-identity case pins the exact declaration atom: the canonical identity carries the defining file, so same-named sibling files never share an atom and every crossing names both. The same-named-sibling controls split into error arms and one runtime-ok control, and the runtime-ok control's sidecar is the oracle at the LuaJIT and JVM production terminals (Node executes it in the JS lane): each backend runs the fixture's own terminal and must render the pinned exit code and transcript byte-exact, so a correct-provider value a backend rejected or mis-tagged fails instead of passing the error-only cases. Execute production artifacts and keep helpers deterministic. Add cases that expose semantic-emitter divergence; never bless AST-only behavior. Host-carrier cases drive one lane protocol on every claimed backend: the sidecar pins the LuaJIT, JVM, and JS backends, the entry terminal runs once, then each declared zero-arity assertion export runs in declaration order on the LuaJIT and JVM production artifacts (Node executes them in the JS lane). A missing lane, a missing host-implementation triplet, or an unexecuted assertion body is a failure, never a pass. Keep this file always synchronized with code.
