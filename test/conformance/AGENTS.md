# Conformance

Maintain specification-indexed frontend and runtime cases with deterministic metadata and exact outcomes. Shared cases run every declared production backend through `CorpusConformanceTest`, using one discovery/preparation/verdict owner and backend-specific artifact launch. Exact rejection is distinct from execution; missing tools and incomplete invocation receipts fail. Bound artifact-launch subprocesses. A class-identity case pins the exact atom of the declaration it names: the canonical identity carries the defining file, so same-named sibling files are distinct declarations and a crossing names both atoms. Fixtures should expose semantic-IR gaps without blessing retained behavior. A fixture's runtime value must arrive through a specification-admitted shape: a table read nested in an array/class literal element or a template interpolation part is E3003 at the read, so a dynamic value that a runtime case needs reaches its use through an explicitly typed intermediate (or the read's own admitted position) rather than through a literal element. Keep companions explicit and focused. A case that reassigns a function-typed binding pins the current-value dispatch the spec requires of reads: the closure body, a nested capture, the copied alias, the repeated loop condition and the branch, imported and host-origin call paths, beside the never-assigned, recursive and arity-extended controls that must keep their statically resolved callees. An arity-extension case pins each statically typed function-value position — a call argument (the same-module, cross-module, stdlib and host-declared parameter cells, including a cataloged stdlib callable source), a `return` expression (the same-module `FUNCTION_RETURN`, an exported sync function's `EXTERNAL_RETURN`, a cross-module exported return and an adapted `RETURN` that is not the function's first), a supplied and a default class field (a default in a declaring unit with no construction, a supplied-only construction and a cross-module construction included), a class field write, an array literal element and an array element write — beside the declaration and assignment controls, the zero-to-one and one-to-two arities, the once-only evaluated ignored target argument, the closure-capturing and function-expression sources and the async marker; its runtime-ok companion pins a function value whose declared type is itself an adapter's (through the binding, field, array element, argument, return and assignment positions, with each level's leading projection and a once-only ignored target argument), a further runtime-ok companion pins a lexically shadowed `int`/`number`/`bytes` name at the parameter, return, class supplied-field, class field-write, array literal and array write positions, each expected value the shadow's own result so an adapter built over the intrinsic fails, a further runtime-ok companion pins an assignment expression used as a value at those positions and at the declaration and variable-assignment controls — the produced target-typed value is the position's source, so an exact target stores it and a wider target adapts it once, a value position materializes the assignment once (a later invocation does not repeat its effect) and a nested assignment chain produces and adapts the inner target-typed value, with the corpus's one-adapter-per-position count pinned on each emitted artifact, a further runtime-ok companion pins an async adapter-valued source at an awaited wider position (the assigned binding cell's adapter value, the awaited zero-to-one adapter value and the exact control), whose completion is the innermost source's result and whose oracle/artifact parity case drives the async entry, its production host-parameter drive pins a shorter DEAL and host-origin value adapting before the exact host cell beside the exact-signature control (the inline host declaration and its Lua/JS/Java implementations stay behaviorally identical) and the table-produced shorter value's exact E8010 rejection, and its runtime-error companions pin the exact E8010 tuple of a dynamically table-produced shorter function value (never silently adapted), while the reverse/mismatching/async-marker rejections stay frontend pins; a callback export's `DEAL_TO_HOST` return cell carries the same return-position adapter and is asserted at the production lowering and on the emitted LuaJIT/JVM callback artifacts (the published JS callback value is covered by the JS emitter suite). A for-of case pins the `let` iteration binding as one mutable cell per iteration: the body's assignment, a capturing closure's read and its own store, and each iteration's independent cell, beside the traversal controls that must survive the mutation (the iterable evaluated once, an appended array's live length and contents, no redirection after the iterable variable is reassigned, break/continue after the mutation, and an awaited resumption in an async body). A for-of iterable that is a call-preserved null-narrowing refinement pins the iterable admission on both carriers: the cleared binding raises the canonical catchable E8001 at the iterable read with zero body visits, and the valid string refinement keeps the once-admitted value through a later closure replacement or body clear, an empty string, astral and combining scalars, each iteration's fresh captured binding, break/continue and an awaited resumption inside the loop body. A `throw` whose operand is a call-preserved null-narrowing refinement pins the operand admission on every backend: the cleared binding raises the canonical catchable E8001 at the operand read's own range with the class descriptor's expected/actual tuple and the caught flag asserted after the try, through the direct, parenthesized and caller-catch forms and inside an async body, while the escaping async export reaches the production invokers as the DEAL error rather than an infrastructure failure; the unchanged non-null `Error` keeps its identity and a handler's field write across the throw, a caught error rethrows unchanged, and the operand expression evaluates exactly once. A short-circuit assignment case pins the `&&`/`||` right operand's branch ownership through every assignment target (variable, array element, table member/index, class field): the skipped operand's throw and effects never run, the selected operand runs exactly once, nested logical results and the receiver→key→RHS order hold, the awaited matrix starts no skipped operation and completes each selected one once through the lane's own async-export host, and the selected operand's throw is pinned as an exact error value and origin, beside the declaration-initializer and return-expression controls. A try/catch narrowing-revert case pins the binding identity of the assigned set in both directions: a try-local shadow declaration (with and without a write to that shadow) and an uncalled nested function body's write keep the enclosing non-null and null-branch refinement and value, while a genuine direct write, a nested try block write and a nested try catch write revert after the enclosing try, and a closure actually called inside the try keeps the static refinement so the cleared binding raises the catchable canonical E8001 at the later typed read.
