# Conformance

Maintain specification-indexed frontend/runtime cases with deterministic metadata and exact outcomes. CorpusConformanceTest owns discovery, preparation, invocation plans and verdicts; backend launch differs only by artifact protocol. Bound subprocesses and reconcile every declared backend/export completion. Missing tools or incomplete invocation fail, never skip. Exact compile rejection is distinct from execution.

- Select membership by declared fixture intent, never current compiler success. Keep companions explicit and focused; preserve denominator and independent focused consumers.
- Pin exact nominal declaration atoms, including same-named siblings. Ordinary crossings and assertions have different projections; include valid controls for each declaration.
- Record reads are unknown. Extract/refine before concrete use, but never let an assertion mask a later parameter/element negative. Admit valid carriers before closure invalidation or fixture-only alias mutation.
- Function-valued variable reassignment cases observe current bindings through captures, aliases, loops, branches and imported/host paths. Never-assigned, recursive and fixed-adapter controls retain static targets.
- Arity adapters cover declaration/assignment, arguments, results, supplied fields, writes, arrays, host/stdlib and async sources. Dynamic shorter signatures reject rather than silently adapt. Ignored arguments still evaluate once. Assignment stores may adapt, but yielded RHS identity/type/effects remain original, including nested assignments and retained callbacks.
- For-of cases preserve evaluated-once iterables, live contiguous traversal and fresh mutable captured iteration cells. Include mutation, alias replacement, break/continue, Unicode and awaited resumption without duplicate batteries.
- Call-preserved refinements can be invalidated through closures. Pin failure at the consuming read before body/storage effects; valid controls preserve the admitted value. Throw controls retain Error identity, original origin and once-only evaluation across direct, parenthesized, caller-catch and async paths.
- Short-circuit assignment covers skipped/selected effects, receiver-key-RHS order, nested results, awaited operations and abrupt completion across storage targets.
- Catch/narrowing controls distinguish scope-correct writes from shadows and uncalled nested bodies. Preserve outer refinements, fresh catch captures, replacement identity and actual closure invalidation.

Use sidecars for observable contracts and code assertions for computed results. Retain distinct consumers when migrating syntax; do not duplicate their complete inventories in policy.
