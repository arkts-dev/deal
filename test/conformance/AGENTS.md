# Conformance

Maintain specification-indexed frontend and runtime cases with deterministic metadata and exact outcomes. Shared cases run every applicable production lane. A class-identity case pins the exact atom of the declaration it names: the canonical identity carries the defining file, so same-named sibling files are distinct declarations and a crossing names both atoms. Fixtures should expose semantic-IR gaps without blessing retained behavior. Keep companions explicit and focused. A case that reassigns a function-typed binding pins the current-value dispatch the spec requires of reads: the closure body, a nested capture, the copied alias, the repeated loop condition and the branch, imported and host-origin call paths, beside the never-assigned, recursive and arity-extended controls that must keep their statically resolved callees. Keep this file always synchronized with code.
