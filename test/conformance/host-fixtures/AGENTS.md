# Host Fixtures

Keep declaration files and JavaScript, Java, or Lua implementations behaviorally identical. Pair valid and invalid boundary cases; distinguish missing exports, invalid values, async shape, and nullability. Fixtures are harness companions, not discovered cases. Host-carrier fixtures declare their classes in the declaration file and carry the same canonical identities, structural fields, function wrappers, and async operations in all three implementations: a class value crosses with its declared top-level fields, a function value is the documented wrapper, and an async export returns a real backend async operation. The corpus lane materializes every declaration under its dotted external identity, so an implementation that names a generated class or function carrier writes that identity text, and any harness project that compiles these implementations imports the same declarations under the same identity form. Numeric declarations and generated JVM carriers use binary64 `number`/`double`, including function signatures and arrays. Host transcript formatting must not infer a language integer kind from a Java box or an integral payload. Async declarations omit the async modifier and use Promise<R> results; implementations still return real backend operations, not first-class source Promise values. The container_mutation triplet is deliberately adversarial: copy only the selected replacement slot into an admitted array, preserving descriptor, identity and all other slots so later element checks remain E8003. Oracle responders mirror that mutation without adding production hooks. JVM fixture classes used by packaged batch drivers must be public. The signature_mutation triplet is deliberately adversarial: it preserves an admitted callable's identity and executable body while invalidating its carried descriptor, so later declaration, parameter and nullable-host E8010 checks remain independently executable without unsafe source casts or production mutability APIs. Record declarations use Record<string, unknown>, including arrays, rather than the retired source table spelling. JSON graph fixtures preserve decoded numeric values without requiring a numeric-variant transport representation or exact nonzero text. Keep generated walkers' path-specific nonfinite and malformed-Unicode failures separate from generic stringify rules. Keep this file always synchronized with code.
