# Host Fixtures

Keep declaration files and JavaScript, Java, or Lua implementations behaviorally identical. Pair valid and invalid boundary cases; distinguish missing exports, invalid values, async shape, and nullability. Fixtures are harness companions, not discovered cases. Host-carrier fixtures declare their classes in the declaration file and carry the same canonical identities, defaults, function wrappers, and async operations in all three implementations: a class value crosses with its declared top-level fields, a function value is the documented wrapper, and an async export returns a real backend async operation. Keep this file always synchronized with code.
