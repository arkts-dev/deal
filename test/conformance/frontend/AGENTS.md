# Frontend Conformance

Test lexing, parsing, checking, and module resolution independently of backend execution. Pin exact compile outcomes, diagnostics, and ranges against the specification. Keep support modules subordinate and cover accepted plus rejected forms. Async implementations and function-type results use Promise notation; extern declarations omit async. For-of bindings are inferred: reject annotations in parser controls and test inferred element incompatibility at its consuming binding. Catch bindings start unknown and Error reads require checked extraction or matching nominal branches. Class literals construct nominal values structurally; required literal fields, including both Error fields, must be explicit so they do not mask an independent diagnostic. Retain field-initializer rejection controls and repin moved ranges at the actual offending token. Keep this file always synchronized with code.
